# Escenarios de atributos de calidad

Formato: Estímulo · Entorno · Respuesta · Medida de respuesta.

| Prio | Atributo | Escenario inicial |
|---|---|---|
| 1 | Disponibilidad | Si un servicio interno no responde, el sistema continúa de forma controlada sin caerse. |
| 2 | Fiabilidad | Si el cliente reintenta el mismo pedido, no se registra dos veces. |
| 3 | Rendimiento | Los pedidos se distribuyen sin que la API espere a todos los servicios internos. |
| 4 | Interoperabilidad | Los servicios intercambian información con los mecanismos y formatos definidos. |
| 5 | Capacidad de respuesta | El estudiante recibe notificación cuando su pedido está listo. |
